# 小米手环/表固件提取教程

::: warning 写在开头
本方法不能保证 100% 提取成功，部分设备就是拿不到直链，属正常现象。
:::

> 突然发现米坛似乎没有固件提取教程，那我应该是全站首发（？）

## 开工之前

- **手机**：安卓。MT 管理器、澎湃 First 都只有安卓版，iOS 走不通。
- **App**：小米运动健康。
- **原理**：在「检测不到新版本」时提交反馈，App 会连带上传一份调试日志，日志里就躺着检查更新接口返回的固件 CDN 直链 —— 我们要做的只是把它翻出来、复制走。

::: tip 选哪个方法
- 只是想要一条链接 → **方法一**，零依赖，几分钟完事。
- 不想翻日志，想一把梭 → **方法二**，第三方软件自动解析。
:::

## 第 0 步：先把日志弄到手机上（两种方法通用）

1. 打开小米运动健康，依次点击 **我的 → 帮助与反馈**。
2. 选择你要提取的手环/表，找到 **固件升级**，选择 **检测不到新版本（服务器配置相关）**。
3. 反馈信息填 `检测不到新版本，提取日志`，联系方式随便填，例如 `12345678910`。
4. **务必勾选「上传问题日志」**。不勾这一步，后面全白干。
5. 点提交反馈，等上传结束，出现「感谢您的宝贵意见」。
6. 回到 **我的** 页，点 **关于**，在页面上连续快速点击顶部的 logo，弹出迁移提示就点确认（这一下会把调试日志落到手机存储里）。

日志最终落在 `Download/wearablelog/` 下的压缩包里。

## 方法一：MT 管理器手动查日志

**使用工具**：MT 管理器（[官网 mt2.cn](https://mt2.cn)，仅安卓）

1. 打开 MT 管理器，定位到 `Download/wearablelog`，打开**最新**的那个压缩包（MT 能直接在包内预览，不必解压）。
2. 找到并打开 `XiaomiFit.main.log`。
3. 点右上角三个点 → 搜索，输入 `fullPackageUrl`，跳到命中处。

   > 搜不到就是这台设备确实没有直链，可以等别人提取，或者换方法二碰碰运气。

4. 从 `fullPackageUrl=` 后面开始，复制到 `changeLog=` 前面那个逗号为止，这一串就是固件下载地址（字段含义见文末附录）。
5. 粘贴到浏览器打开下载。恭喜你，你已经有自己的固件了。

## 方法二：澎湃 First 自动解析

**使用工具**：澎湃 First（作者「花海」「沐风」，[123 云盘下载](https://1816736646.mshare.123pan.cn/123pan/Vot6Vv-Ur3e3)，或加官方群 `1061504239`）

1. 先做完上面的 **第 0 步**，把日志压缩包拿到手。
2. 打开澎湃 First，注册并登录。
3. 首页找到 `固件` 栏，点击 `穿戴固件提取`，在「上传日志」处点 `自动识别`；首次会要求授予所有文件访问权限，识别不到就点「选择 zip」，手动定位到 `Download/wearablelog` 里的最新压缩包。
4. 点开始解析，软件会自己抽出链接并复制。恭喜你，你已经有自己的固件了。

::: warning 第三方软件
澎湃 First 不是小米官方工具，且需要「所有文件访问权限」，介意就走方法一。软件本身不归我维护，遇到 bug 加群 `1061504239` 反馈，以软件内说明为准。
:::

## 注意事项

1. **不能保证 100% 成功**，走 CDN 鉴权、只下发增量包的机型就是提不出来，别死磕。
2. **必须勾选「上传问题日志」**，否则日志里压根没有接口返回。
3. 日志里 `diffUrl` 有值说明只给了增量包（几十到几百 KB），当前版本往往得逐级升上去，不一定能直刷。
4. 链接带签名和过期时间，拿到就尽快下；提取本身不动设备，刷机前请自己备份并核对包体（`md5` 字段能对）。
5. 还是提不出来？加 [Q 群](https://qm.qq.com/q/kKoB0HseMo) `1003141252` 问，**「提不出来」这个问题不受理**（先确认自己勾了上传日志）。

## 附：日志字段速查

`fullPackageUrl` 那一行拆开是什么，以及几个容易踩的坑。不想看可以直接跳过，不影响照着上面的步骤做完。

一条正常命中长这样（以下是真实日志，小米手环 9 Pro）：

``` log
2026-11-01 16:33:45.407|3.60.1|I|CheckUpdate_17864_17864|checkUpdate getLatestVersion success LatestVersion(version=3.1.190, fullPackageUrl=https://iot-ota-cdn.io.mi.com/miio_fw/b59c5bae39870c5a1846fbf505741faa_upd_miwear.watch.n67cn.bin?GalaxyAccessKeyId=5721718224520&Expires=1805183822518&Signature=S62rV1jFWuHbbl5VBPvCLwuGot8=, changeLog=• 欢迎使用小米手环9 Pro，感谢您的支持！为了一些必要的设备体验优化，我们强烈推荐您升级此版本。
• 更新日志：
• 新增支持垂腕通知显示设置，灵活管控垂腕时消息展示，更好保护隐私。
• 升级表盘相关能力，支持删除预装表盘。
• 优化睡眠数据同步效率，数据同步速度更快。
• 提升手环解锁 HyperOS 手机的安全性。
• 增加运动结束提醒，运动使用体验优化。, md5=b59c5bae39870c5a1846fbf505741faa, uploadTime=0, diffUrl=, diffMd5=, force=false, isValid=true), currentVersion = 3.1.190
2026-11-01 16:33:45.407|3.60.1|I|CheckUpdate_17864_17864|compareFirmwareVersion2() called with: latestVersion = 3.1.190, currentVersion = 3.1.190
```

| 字段 | 原始内容 | 解析 |
|---|---|---|
| `LatestVersion.version` | 3.1.190 | 官方最新固件版本 |
| `fullPackageUrl` | https://... | 固件下载地址 |
| `changeLog` | 5条更新说明 | 新版本改了啥：隐私通知、删表盘、睡眠同步快、解锁更安全、运动结束提醒 |
| `md5` | b59c... | 文件的“指纹”，用来检查文件完不完整 |
| `uploadTime` | 0 | 文件上传时间 |
| `diffUrl` | 空 | 差异包链接 |
| `diffMd5` | 空 | 差异包指纹 |
| `force` | false | 是否强制更新 |
| `isValid` | true | 这个更新信息是有效的 |
| `currentVersion` | 3.1.190 | 手环现在的版本 |
| `compareFirmwareVersion2()` | - | 最新版和当前版比对 |
| `latestVersion` 参数 | 3.1.190 | 最新版是 3.1.190 |
| `currentVersion` 参数 | 3.1.190 | 当前版是 3.1.190 |

- 字段是 `changeLog`，**大写 L**，按 `changelog` 搜会一条都搜不到。
- 连着 `fullPackageUrl=` 一起选中也行，粘到地址栏前把那截前缀删掉；更稳的做法是只选 `https://` 到逗号之间。
- 最后那行 `compareFirmwareVersion2()` 只是版本比较，不影响提取。
