## 方法一

**使用工具**：小米运动健康 + MT管理器

1. 打开小米运动健康，依次点击**我的** → **帮助与反馈**。
   然后选择你要提取的环/表，找到**固件升级**选项，选择**检测不到新版本（服务器配置相关）**。
   反馈信息填“**检测不到新版本，提取日志**”，联系方式随便填，例如 `12345678910`。
   *重要！！！* 一定要勾选**上传问题日志**，然后点击提交反馈，等待上传结束，提示感谢您的宝贵意见。
   回到**我的**页面，点击关于，连续点击上面的logo，出现迁移提示时点确认。

2. 打开MT管理器（如果没有请点击 [此处](https://mt2.cn) 下载，仅支持安卓手机！！），定位到 `Download/wearablelog` 目录，打开最新的压缩包，找到并打开 `XiaomiFit.main.log` 文件。
   点击右上角三个点，选择搜索，在弹出的输入框中输入 `cdn.cnbj0`（如果搜不到那就是没有，可以等其他人提取），然后定位到对应的地方。
   找到前面的 ***fullPackageUrl=*** ，一直到 ***，changelog*** 前面，这个链接就是你的固件下载地址。恭喜你，你已经找到了你的固件，此时，将此链接复制到浏览器打开即可下载。

## 方法二

**使用工具**：小米运动健康 + 澎湃First
（注：本软件是由开发者“花海”与“沐风”开发的一款软件，可在 [此处的123云盘](https://1816736646.mshare.123pan.cn/123pan/Vot6Vv-Ur3e3) 或 官方QQ交流群（下面有群号） 下载）

1. 打开小米运动健康，依次点击**我的** → **帮助与反馈**。
   然后选择你要提取的环/表，找到**固件升级**选项，选择**检测不到新版本（服务器配置相关）**。
   反馈信息填“**检测不到新版本，提取日志**”，联系方式随便填，例如 `12345678910`。
   勾选**上传问题日志**，然后点击提交反馈，等待上传结束，提示感谢您的宝贵意见。
   回到**我的**页面，点击关于，连续点击上面的logo，出现迁移提示时点确认。

2. 打开澎湃First软件，点击右下角小人，点击登录/注册按钮，按照提示注册一个账号并登录。

3. 点击首页的“穿戴固件下载”，点击最上面的“穿戴固件链接提取”，在上传日志那里点击“自动识别”按钮，即可自动识别日志文件。
   如未找到，请点击“选择zip”按钮，定位到 `Download/wearablelog` 目录，选择最新的压缩包，然后点开始解析，即可自动解析出下载链接并快速复制。恭喜你，你已经找到了你的固件，此时，将此链接复制到浏览器打开即可下载。

   ::: tip
   方法二的第2和第3点具有时效性，软件在更新但文档可能会过时，请以软件内容为准
   :::
